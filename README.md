WhatsFlow

WhatsFlow is a privacy-focused WhatsApp chat analysis tool with a retro cyberpunk-inspired interface.
Upload exported WhatsApp chat files and analyze conversations directly in your browser without sending data to external servers.

Features
Upload .txt or .zip WhatsApp exports
Local-first processing
Privacy-focused design
Retro terminal inspired UI
Fast chat parsing and analysis
Responsive interface
